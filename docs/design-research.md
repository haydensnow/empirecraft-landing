# EmpireCraft design research

Reviewed 21 September 2026. These are design observations, not measured conversion results.

## What works for an SMP landing page

- **Show the actual world.** BlossomCraft uses community and event images to show the experience. EmpireCraft already has a strong spawn screenshot, so it remains the main visual instead of generic promotional art.
- **Explain who the server suits.** BlossomCraft leads with relaxed, community-focused survival; Crucible describes its economy and gameplay. EmpireCraft’s useful differences are its small whitelist, mostly vanilla gameplay, and no activity requirement.
- **Make joining concrete.** Crucible surfaces the address, edition, and connection steps. EmpireCraft needs an application first: its primary action leads to the Discord/approval instructions; copying the address is secondary and marked for already-whitelisted players.
- **Borrow Minecraft’s visual vocabulary.** The official site combines expansive game imagery, dark navigation, pixel headings, and green beveled buttons. Here those cues sit alongside readable system-sans body text and restrained texture use.
- **Keep mobile simple.** Visible navigation wraps onto a second row, cards stack, text remains selectable, and the heavy live map loads only when requested. No carousel, autoplay, fake online count, or fabricated testimonials.

## Content basis

Server address, Discord invitation, map, staff handles, six application questions, community dates, version 26.2, plugin details, and Patreon URL came from the existing site. The version is labeled “Server version,” not “Latest update.” No claim of a live server-status check is made. Discord remains the source for current access/compatibility questions.
